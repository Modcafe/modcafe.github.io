# Install Fallback

You can download and install Fallback using three different methods:

### 1. Installing Fallback as Data Pack on a existing world
1. Download Fallback from [Modrinth](https://modrinth.com/mod/fallback)
2. Go to your Minecraft Instance
3. Select the world in the world screen
4. Click on "Edit" and then "Open World Folder"
5. Locate the Folder `datapacks`
6. Insert the `.zip` File there
7. Open the world and type `/reload`

### 2. Installing Fallback as Data Pack on a new world
1. Download Fallback from [Modrinth](https://modrinth.com/mod/fallback)
2. Go to your Minecraft Instance
3. Create a new World
4. Click on "More" and then "Datapacks"
5. Insert the `.zip` File into the folder
6. Create and open the world

### 3. Installing Fallback as a Mod
::: danger Why is there no Tutorial for my Launcher?
Every Mod-Loader and Programm installs Mods differently. We can't provide the ONE always working answer.
:::

::: details via Modrinth App (recommended)
1. Go to the Launcher
2. Click on "Library" at the sidebar
3. Open your instance or create a new one
4. Click on "Browse Content"
5. Search for `Fallback` and click on "Install"
6. Start the Instance
:::

::: details via Dawn Client
1. Go to the Launcher
2. Click on "Profiles/Mods" at the top
3. Open your Profile or create a new one
4. Click on "Add Content"
5. Click on "Browse Modrinth"
6. Search for `Fallback` and click on "Install"
7. Start the Profile
:::

::: details via NoRiskClient
1. Go to the Launcher
2. Click on "Profiles"
3. Open your Profile or create a new one
4. Click on "Add Mods"
5. Click on "Modrinth" and search for `Fallback`
6. Click on "Install"
7. Start the Profile
:::

::: details via Lunar Client
1. Go to the Launcher
2. Click on "Explore"
3. Search for `Fallback`
4. Click on "Install" and choose your Profile/Instance
5. Start the Instance
:::

If you've installed Fallback, you're ready to go.
